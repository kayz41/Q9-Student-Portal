# Question 09 — ISBAT University Student Self-Service Portal

A student portal practical with a dashboard, courses page and fee-statement placeholder.

## Pages and files
- `index.html` — redirects visitors to the dashboard
- `dashboard.html` — student dashboard
- `courses.html` — course information and timetable
- `fee-statement.html` — fee statement placeholder
- `portal.css` — shared external stylesheet

The university logo is referenced from the preserved master coursework repository because it is shared with Question 01.

## Run locally
Open `index.html` or `dashboard.html` in a browser.
